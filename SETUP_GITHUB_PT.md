# Publicar COOPER RUN no GitHub — guia rápido

Este pacote está preparado para o repositório:

```text
https://github.com/MmmPT/cooper-run-zx-spectrum
```

A página pública ficará em:

```text
https://mmmpt.github.io/cooper-run-zx-spectrum/
```

## 1. Criar o repositório

No GitHub, cria um repositório público chamado exatamente:

```text
cooper-run-zx-spectrum
```

Descrição sugerida:

```text
A vertical arcade racing game for the ZX Spectrum. Five timed stages, rival cars, traffic, source code and TAP release.
```

Ao criar o repositório, não peças ao GitHub para adicionar README, `.gitignore` ou licença, porque estes ficheiros já estão incluídos.

## 2. Carregar os ficheiros

Descompacta o pacote e carrega **todo o conteúdo desta pasta** para a raiz do repositório, usando `Add file` → `Upload files`.

Mensagem sugerida para o primeiro commit:

```text
Initial release of Cooper Run
```

## 3. Ativar a página

No repositório, abre:

```text
Settings → Pages
```

Escolhe:

```text
Source: Deploy from a branch
Branch: main
Folder: /docs
```

Carrega em `Save`. A publicação pode demorar alguns minutos.

## 4. Resultado

- Código e ficheiros: `https://github.com/MmmPT/cooper-run-zx-spectrum`
- Página do jogo: `https://mmmpt.github.io/cooper-run-zx-spectrum/`
- Download direto: `https://mmmpt.github.io/cooper-run-zx-spectrum/downloads/Cooper_Run_ZX_Spectrum_v1.0.zip`

COOPER RUN — ZX SPECTRUM
================================

Thirty cars stand between you and victory.

COOPER RUN is a vertical arcade racing game for the ZX Spectrum. Race through
five timed stages, overtake the rival cars and climb from 30th position to
first. Ordinary traffic does not count towards your race position, but it can
still ruin a perfect run.

VERSION 1.1
-----------
Version 1.1 introduces a new loading screen and a redesigned main-menu logo
while retaining the established five-stage racing gameplay.

CONTROLS
--------
Q                  Accelerate
A                  Brake
O / P              Turn left / right
Kempston joystick  Up or fire = accelerate; down = brake; left/right = turn

MENU OPTIONS
------------
1  Start race
2  Instructions
3  Difficulty: Easy / Normal / Hard
4  Control: Keys / Kempston
5  Music: On / Off

HOW TO LOAD
-----------
Real ZX Spectrum:
1. Type LOAD ""
2. Press ENTER.
3. Start the tape or play the TAP file using your chosen device.
4. The game loads and starts automatically.

Emulator:
1. Open or insert CooperRun.tap.
2. Start tape playback if it does not begin automatically.
3. The game loads and starts automatically.

COMPATIBILITY
-------------
ZX Spectrum 48K or compatible model/emulator. Compatible 128K systems can use
AY music; the game remains playable on a standard 48K machine.

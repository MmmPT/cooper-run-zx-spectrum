# COOPER RUN v1.1

Version 1.1 is a visual presentation update for COOPER RUN on the ZX Spectrum.

## What's new

- A completely new loading screen, with artwork by **Mário Viegas**.
- A redesigned COOPER RUN logo for the main menu.
- The main-menu logo is now stored separately from the loading screen instead
  of reusing the loading artwork.
- Updated screenshots, release package and GitHub Pages presentation.

The established five-stage racing gameplay, difficulty modes and control
options remain unchanged.

## Files

- `CooperRun.tap` — ready-to-play v1.1 tape image
- `CooperRun.bin` — released v1.1 code block loaded at address 32768
- `Cooper_Run_ZX_Spectrum_v1.1.zip` — player download package

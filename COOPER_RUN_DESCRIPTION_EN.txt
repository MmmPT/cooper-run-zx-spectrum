COOPER RUN — ZX Spectrum

Thirty cars stand between you and victory.

COOPER RUN is an original vertical arcade racing game for the ZX Spectrum.
Race through five timed stages, overtake the rival cars and climb from 30th
position to first.

Version 1.1 introduces a new loading screen with artwork by Mário Viegas and a
redesigned main-menu logo, while retaining the established racing gameplay.

FEATURES

- Five timed stages of 1100 metres
- Start in 30th position and fight towards first place
- Rival cars and independent traffic
- Easy, Normal and Hard difficulty settings
- Keyboard and Kempston joystick support
- Records table
- ZX Spectrum 48K compatible
- AY music on compatible 128K systems

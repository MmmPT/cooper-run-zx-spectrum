# COOPER RUN v1.0

The first public release of COOPER RUN for the ZX Spectrum.

## Goal

Complete five timed stages of 1100 metres and climb from 30th position to first. Rival cars improve your position when overtaken; ordinary traffic only gets in the way.

## Files

- `CooperRun.tap` — ready-to-play tape image
- `CooperRun.bin` — released code block loaded at address 32768
- `Cooper_Run_ZX_Spectrum_v1.0.zip` — player download package
